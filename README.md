# ATM Management System

A console-based ATM Management System developed using **Java, JDBC, and SQLite**.  
The application allows users to create and manage bank accounts while storing account data persistently in an SQLite database.

## Features

- User Registration
- User Login Authentication
- Check Account Balance
- Deposit Money
- Withdraw Money
- Change PIN
- Delete Account
- Logout
- Input Validation
- SQLite Database Integration
- CRUD Operations

## Technologies Used

- **Java**
- **JDBC (Java Database Connectivity)**
- **SQLite**
- **SQL**
- **IntelliJ IDEA**
